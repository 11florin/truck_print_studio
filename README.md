# Truck Print Studio

Django e-commerce application for UK road transport print designs. The project
supports a product catalogue, categories, search, filters, size variants,
session-based bags, guest checkout, accounts, wishlists, reviews and Stripe
Checkout payments.

## Local development

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py runserver
```

Keep real secrets only in `.env` or the hosting provider's environment
variables. Never commit `.env`.

## Validation

```bash
python manage.py check
python manage.py test
python manage.py collectstatic --no-input
```

## Stripe test mode

Use `sk_test_...` and the webhook secret generated by:

```bash
stripe listen --forward-to localhost:8000/orders/stripe/webhook/
```

For production, configure `sk_live_...` and a separate HTTPS webhook endpoint
in Stripe Dashboard. The webhook URL is:

```text
https://YOUR_DOMAIN/orders/stripe/webhook/
```

## Deployment

The included [Procfile](./Procfile) starts Gunicorn. A PostgreSQL hosting
provider should expose its connection string as `DATABASE_URL`.

For a Render web service:

1. Connect the GitHub repository and select the deployment branch.
2. Set the build command to:
   ```text
   pip install -r requirements.txt && python manage.py collectstatic --no-input && python manage.py migrate
   ```
3. Use the start command from `Procfile`, or:
   ```text
   gunicorn truck_print_config.wsgi:application
   ```
4. Add the production variables listed in the hosting provider's Config Vars:
   `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`,
   `DATABASE_URL`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` and
   `STRIPE_CURRENCY`.
5. Add the deployed hostname to `ALLOWED_HOSTS` and
   `CSRF_TRUSTED_ORIGINS`.
6. Configure a Stripe HTTPS webhook for
   `/orders/stripe/webhook/`.

`collectstatic` is served by WhiteNoise. User-uploaded media is not durable on
ephemeral hosting filesystems; production media should use object storage such
as S3 or Cloudinary.
