# User stories

## Visitor and catalogue

- As a visitor, I can browse featured products on the home page.
- As a visitor, I can browse products by category.
- As a visitor, I can search by product name or description.
- As a visitor, I can filter products by category and product type.
- As a visitor, I can open a product detail page and see its image, price and description.
- As a visitor, I can choose a size for T-shirts and Hoodies before adding them to my bag.
- As a visitor, I can add products without sizes, such as Mugs, to my bag.

## Bag and checkout

- As a guest, I can see product images, quantities, sizes and totals in my bag.
- As a guest, I can remove a specific size variant from my bag.
- As a guest, I can complete checkout without creating an account.
- As a customer, I am redirected to Stripe Checkout to pay securely.
- As a customer, I can see a confirmation after Stripe confirms payment.
- As a customer, I can see an order remain pending until the Stripe webhook confirms it.

## Accounts and customer features

- As a visitor, I can register, log in and log out.
- As an authenticated user, I can access my profile and order history.
- As an authenticated user, I can add and remove wishlist products.
- As an authenticated user, I can create, edit and delete my own reviews.
- As an authenticated user, I cannot edit another user's review or view another user's order.
